Лабораторная работа 1. Вычисления характеристик многочленов над конечными полями. 
Задание.  Необходимо разработать приложение для действий с многочленами над полем F_q  = {0, 1, …, q-1}. 
Программа должна выполнять следующие операции с многочленами: 
1. Арифметические действия: сложение, вычитание, умножение, вычисление обратного по модулю другого многочлена, деление многочленов в модулярном кольце многочленов по модулю неприводимого многочлена.
2. Проверять многочлен на неприводимость двумя способами: с помощью сведения к многочленам меньших порядков и с помощью универсального критерия неприводимости.
3. Вычислить число неприводимых многочленов произвольной степени над произвольным полем с помощью формулы, использующей функцию Мебиуса.
4. Выполнять вспомогательные действия: вычислять НОД полиномов, функцию Мебиуса, возведение полинома в степень, функцию Эйлера и т.д.
5. Находить порядок произвольного многочлена.
6. Проверять многочлены на примитивность. Вычислять число примитивных многочленов заданной степени.
7. Составить таблицы всех неприводимых и примитивных многочленов от 5 до 10-й степени над полем F_2 .
8. Строить круговые многочлены произвольной степени.

## Соответствие реализации требованиям лабораторной работы

### 1. Арифметика многочленов над конечными полями

**Реализовано в:** `lib/field.py`, `lib/polynomial.py`

* Сложение многочленов — `Polynomial.__add__()`
* Вычитание многочленов — `Polynomial.__sub__()`
* Умножение многочленов — `Polynomial.__mul__()`
* Деление многочленов с остатком — `Polynomial.divmod()`
* Получение частного — `Polynomial.__floordiv__()`
* Получение остатка — `Polynomial.__mod__()`
* Умножение многочлена на скаляр — `Polynomial.scalar_mul()`
* Нахождение обратного элемента конечного поля — `Field.inverse()`
* Возведение многочлена в степень — `Polynomial.__pow__()`
* Возведение многочлена по модулю — `Polynomial.pow_mod()`
* Нахождение обратного многочлена по модулю — `Polynomial.inverse_mod()`

Для нахождения обратного многочлена используется расширенный алгоритм Евклида.

---

### 2. Проверка неприводимости многочленов

**Реализовано в:** `lib/irreducibility.py`

Реализованы два способа проверки неприводимости:

* проверка с использованием таблицы — `is_irreducible_by_table()`;
* проверка по универсальному критерию — `is_irreducible_by_criterion()`.

Дополнительно реализованы:

* построение таблицы многочленов — `build_table_polynomial()`;
* поиск неприводимых многочленов заданной степени — `find_irreducible()`.

При проверке по критерию используется НОД многочленов.

---

### 3. Подсчёт количества неприводимых многочленов

**Реализовано с использованием:** `lib/mobius.py`, `lib/irreducibility.py`

Для вычислений используются:

* функция Мёбиуса — `mobius()`;
* получение простых делителей — `prime_divisors()`;
* получение делителей числа — `divisors()`.

Функция Мёбиуса используется при построении полиномов, связанных с подсчётом и проверкой неприводимых многочленов.

---

### 4. Вспомогательные операции

**Реализовано в:** `lib/gcd.py`, `lib/mobius.py`, `lib/euler.py`, `lib/polynomial.py`

* НОД многочленов — `gcd()`
* Расширенный алгоритм Евклида — `extended_gcd()`
* Функция Мёбиуса — `mobius()`
* Поиск простых делителей — `prime_divisors()`
* Получение делителей числа — `divisors()`
* Возведение многочлена в степень — `Polynomial.__pow__()`
* Возведение многочлена по модулю — `Polynomial.pow_mod()`
* Функция Эйлера — `euler_phi()`

---

### 5. Нахождение порядка произвольного многочлена

**Реализовано в:** `lib/order.py`, `lib/polynomial.py`

Реализовано нахождение порядка многочлена с использованием возведения по модулю.

Основная функция:

* `order()`

Для вычислений используются:

* `Polynomial.pow_mod()`;
* `prime_divisors()` для разложения числа на простые множители.

Порядок многочлена определяется как минимальное положительное число `k`, для которого выполняется:

```text
f^k ≡ 1 (mod m)
```

### 8. Построение циклотомических (круговых) многочленов

**Реализовано в:** `lib/cyclotomic.py`, `lib/polynomial.py`

Реализовано построение циклотомических многочленов произвольного порядка.

Основные функции:

* `cyclotomic_polynomial()`;
* `Polynomial.cyclotomic()`.

При построении используются:

* функция Мёбиуса — `mobius()`;
* получение делителей числа — `divisors()`;
* арифметические операции над многочленами;
* деление многочленов.

Построение основано на формуле:

```text
Φₙ(x) = ∏(xᵈ - 1)^μ(n/d)
```

где `μ` — функция Мёбиуса, а произведение выполняется по всем делителям `n`.
