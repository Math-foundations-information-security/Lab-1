«Математические основы защиты информации и информационная безопасность»

Лабораторная работа 1. Вычисления характеристик многочленов над конечными полями. 
Задание.  Необходимо разработать приложение для действий с многочленами над полем F_q  = {0, 1, …, q-1}. 
Программа должна выполнять следующие операции с многочленами: 
1. Арифметические действия: сложение, вычитание, умножение, вычисление обратного по модулю другого многочлена, деление многочленов в модулярном кольце многочленов по модулю неприводимого многочлена.
2. Проверять многочлен на неприводимость двумя способами: с помощью сведения к многочленам меньших порядков и с помощью универсального критерия неприводимости.
3. Вычислить число неприводимых многочленов произвольной степени над произвольным полем с помощью формулы, использующей функцию Мебиуса.
4. Выполнять вспомогательные действия: вычислять НОД полиномов, функцию Мебиуса, возведение полинома в степень, функцию Эйлера и т.д.
5. Находить порядок произвольного многочлена.
6. Проверять многочлены на примитивность. Вычислять число примитивных многочленов заданной степени.
7. Составить таблицы всех неприводимых и примитивных многочленов от 5 до 10-й степени над полем F_2 .
8. Строить круговые многочлены произвольной степени.
